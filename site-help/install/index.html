    Install Strange Country on a Mac

    Return to website help

    This installation is normally completed once. Afterward, everyday work uses the strange-country command and iA Writer.

    Before you begin

    You need:

    • a Mac with an internet connection;
    • iA Writer installed;
    • the unzipped Strange Country project folder;
    • your own GitHub account, with access to the already-prepared private website repository.

    Never place a password, authentication code, private key, recovery code, or confidential source document inside the project folder or an article folder.

    If you are beginning from the downloaded package, double-click START HERE.html. It opens as an ordinary browser page and leads into these same instructions.

    1. Put the project in its permanent location

    Open Finder and move the unzipped project folder into Documents. Rename it exactly:

    Strange Country

    Its final location must be:

    Home → Documents → Strange Country

    Do not work from Downloads or directly from the ZIP file.

    2. Open Terminal and check Homebrew

    Open the Terminal application from Spotlight or Applications → Utilities. Type:

    brew --version

    If a Homebrew version appears, continue. If Terminal says command not found, install Homebrew from its official website, follow the PATH instructions shown by its installer, then close and reopen Terminal.

    3. Run the one-time setup

    Copy and paste these two lines into Terminal, pressing Return after each:

    cd ~/Documents/"Strange Country"
./scripts/setup_macos.sh

    The setup installs or checks Hugo, Git, GitHub CLI, and Python. It also installs the friendly strange-country command.

    The setup may open GitHub’s browser sign-in. Sign into your own GitHub account. Do not use another person’s account on your permanent Mac.

    4. Close and reopen Terminal

    When setup finishes, close every Terminal window. Open a fresh Terminal window and type:

    strange-country

    The command moves Terminal into the project folder and displays the everyday commands.

    The command is implemented as a small zsh function installed automatically in your home folder. You do not need to understand or edit zsh configuration. The installer creates ~/.strange-country-command.zsh and adds one guarded loading line to ~/.zshrc.

    5. Connect this Mac to the prepared website

    The repositories and public website should already exist. Follow Connect this Mac to the existing website. You will run one command using your GitHub username; it downloads the official private project and keeps this installation package as a dated backup.

    You do not create repositories, configure GitHub Pages, or manage deployment keys.

    6. Run the system check

    After the connection succeeds and Terminal has been reopened, type:

    strange-country update
strange-country doctor

    The final line should confirm that the site is ready to build.

    7. Add one writing location to iA Writer

    In iA Writer, add this single folder to the Library or Organizer:

    Documents/Strange Country/content/posts

    This is the only project folder you need in iA Writer. It contains your article folders and nothing else. It may be empty before you create the first article.

    Do not put loose Markdown files directly in posts. Do not create category folders inside it. Always create a new article with:

    strange-country new "Article Title"

    The command makes the correctly named article folder and its index.md writing file for you.

    8. Open the browser guide at any time

    From any Terminal window, type:

    strange-country guide

    Keep Terminal open while reading the local guide. To stop it, return to Terminal and press Control-C.

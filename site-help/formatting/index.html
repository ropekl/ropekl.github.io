Formatting your writing

Strange Country uses Markdown, a simple formatting system used by iA Writer.

This guide shows the formatting you are most likely to use first, followed by less common options. Common formatting such as headings, links, lists, bold, and italics can also be added with the iA Writer Format menu.

For scripts and screenplays, see Formatting scripts and screenplays.

Everyday formatting

Paragraphs and line breaks

Leave one completely empty line between paragraphs:

This is the first paragraph.

This is the second paragraph.

If you need a new line without starting a new paragraph, put a backslash \ at the end of the line:

MARA\
You said it was finished.

ELIAS\
I said it was nearly finished.

The backslash does not appear on the website. Do not put a space after it.

Headings

Note: The title of the Post or Misc Musing is added to the page automatically. Do not type it again at the top of the document.

Use headings to divide a longer piece into clearly named parts.

For a heading that begins a new part of the piece, use two number signs:

## The Journey North

If that part needs a smaller heading within it, use three:

### The Last Evening in Naples

Leave one completely empty line before and after a heading, like this:

The road had become almost impassable by dusk.

## The Journey North

We left before sunrise the following morning.

Use heading levels in order rather than skipping from ## to ####.

Italics, bold, and strikethrough

For italics, put one asterisk on each side of the words:

I had never seen *La Dolce Vita* before.

For bold, put two asterisks on each side:

The final sentence is **particularly important**.

For strikethrough, put two tildes ~~ on each side:

The meeting was on ~~Thursday~~ Friday.

Links

To turn words into a link, put the words the reader will see inside square brackets, followed immediately by the web address inside parentheses:

The report is available from the [National Archives](https://www.archives.gov/).

On the website, National Archives will appear as the clickable link.

For an email link, use:

[Write to the editor](mailto:editor@example.com)

Quotations

For a short quotation within a paragraph, use ordinary quotation marks:

She described the journey as “the longest night of my life.”

For a longer quotation that you want to set apart from the surrounding text, begin each paragraph with >:

> This is a longer quotation set apart from the main text.
>
> A second paragraph of the same quotation begins this way.

If you want to identify the source, put the attribution in ordinary text beneath the quotation:

> It was the best of times, it was the worst of times.

Charles Dickens, *A Tale of Two Cities*

How it appears

It was the best of times, it was the worst of times.

Charles Dickens, A Tale of Two Cities

Lists

For a bulleted list, begin each item with a hyphen:

- First item
- Second item
- Third item

For a numbered list, begin each item with a number followed by a period:

1. First step
2. Second step
3. Third step

To put a list inside another list, indent the smaller list beneath its parent item:

- France
    - Paris
    - Lyon
- Italy
    - Rome
    - Naples

You can also nest a numbered list:

1. Prepare the article
    1. Check the text
    2. Check the images
2. Preview the website
3. Publish

How a nested list appears

  • France
    • Paris
    • Lyon
  • Italy
    • Rome
    • Naples

Leave one completely empty line before and after a list, like this:

These were the three places we visited.

- Palermo
- Naples
- Rome

We returned home the following week.

Footnotes

To add a footnote, put a footnote marker immediately after the relevant word or sentence:

The building was completed in 1927.[^1]

Then put the matching footnote text at the end of the document:

[^1]: Construction had begun three years earlier.

A complete example looks like this:

The building was completed in 1927.[^1]

[^1]: Construction had begun three years earlier.

Use a different marker for each footnote:

[^1]
[^2]
[^3]

The footnotes will be collected and displayed automatically on the published page.

How it appears

The building was completed in 1927.1

Images and captions

Before adding an image to your writing, put the image file in the folder belonging to that Post or Misc Musing. See Add an image for instructions on where to put it and how to name the file.

To place the image in your writing, put it on a line of its own, with one completely empty line before and after it:

The station was already deserted by the time we arrived.

![An empty railway platform in winter](railway-platform.jpg)

The last train had passed several hours earlier.

The words inside the square brackets briefly describe what the image shows. The filename inside the parentheses must match the image’s actual filename exactly.

To add a visible caption, put the caption in quotation marks after the filename:

![An empty railway platform in winter](railway-platform.jpg "The station shortly after dawn")

The description inside the square brackets does not appear as the caption. It describes the image for readers who cannot see it. The text in quotation marks is the caption that appears on the page.

Do not add width or size instructions. Strange Country will size the image automatically.

Dividers

To place a horizontal divider between two parts of your writing, put three hyphens on a line of their own:

---

Leave one completely empty line before and after the divider:

We stayed there until the end of summer.

---

By October, everything had changed.

How it appears

We stayed there until the end of summer.

By October, everything had changed.

Further formatting

Tables

To make a table, use vertical bars | to separate the columns:

| City | Date | Notes |
|---|---:|---|
| Palermo | 5 August | Arrival |
| Naples | 9 August | Departure |

The second line is required. Colons control the alignment of a column:

  • :--- = left
  • ---: = right
  • :---: = centred

How it appears

CityDateNotes
Palermo5 AugustArrival
Naples9 AugustDeparture

Very wide tables may require horizontal scrolling on a narrow screen.

Computer commands and code

If you want a Terminal command, filename, or short piece of computer code to stand out from the surrounding sentence, put one backtick on each side:

Enter `strange-country preview` in Terminal.

For a longer piece of code or computer text, put three backticks on a line before it and three on a line after it:

```
First line
Second line
Third line
```

How it appears

First line
Second line
Third line

Definition lists

For a glossary-style list, put the term on one line. On the next line, begin its explanation with a colon:

Assonance
: The repetition of similar vowel sounds.

Enjambment
: A sentence or phrase that continues beyond the end of a poetic line.

Leave one completely empty line between separate entries.

How it appears

Assonance
The repetition of similar vowel sounds.
Enjambment
A sentence or phrase that continues beyond the end of a poetic line.

Show Markdown symbols as ordinary text

If you want a symbol or character that is normally used by Markdown for formatting to appear as ordinary text, put a backslash \ immediately before it.

For example:

\*Terms and conditions apply\*

How it appears

*Terms and conditions apply*

The backslash itself will not appear on the website.

Webpage code and special layouts

Do not paste HTML or other webpage code into a Post or Misc Musing. Strange Country will not publish raw HTML from ordinary writing.

For normal formatting, use the Markdown options in this guide.

If you need a special layout that these options cannot provide, ask for technical assistance rather than pasting scripts, style code, iframe code, or copied webpage HTML into the document.

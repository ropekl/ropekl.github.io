Back up your work

iA Writer saves your changes on this computer automatically.

To keep an additional private copy of all your Strange Country writing, images, and website data:

strange-country backup

You do not need to name a particular piece. The command backs up all current work together.

Keep Terminal open until it says the backup is complete. Backing up does not publish anything or change the public website.

The Publish, Unpublish, Change Title, Delete, and Update commands also create the appropriate backup automatically before making consequential changes.

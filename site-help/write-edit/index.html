Create and edit writing

New Posts and Misc Musings begin Private, so they are not publicly visible until you mark them Ready and publish them.

Create a new Post

Open Terminal and enter:

strange-country new

Press Return.

Terminal will ask for the title of the Post. Type the title exactly as you want it to appear on the website, then press Return.

Strange Country creates the Post and opens its writing document in iA Writer.

Click in the document and begin writing. You do not need to type the title again at the top.

iA Writer saves your work automatically. Do not use Save As or create another copy of the document.

The new Post begins Private.

Create a new Misc Musing

Open Terminal and enter:

strange-country new-musing

Press Return.

Terminal will ask for the title. Type it exactly as you want it to appear on the website, then press Return.

Strange Country creates the Misc Musing and opens it in iA Writer. Write and edit it in the same way as a Post. You do not need to type the title again at the top, and iA Writer saves your work automatically.

A new Misc Musing begins Private. Preview it, mark it Ready to publish, and publish it in the same way as a Post.

Find and open existing writing

To find a Post or Misc Musing by title, open Terminal and enter:

strange-country find

Press Return.

Type one or more words from the title and press Return.

Strange Country shows matching Posts and Misc Musings, together with their state: Private, Ready to publish, or On website. A published piece that has unpublished edits may also say Changes waiting to be published.

Type the number beside the piece you want and press Return. Even if only one result appears, type 1 and press Return.

The exact writing document opens in iA Writer.

Find does not search the About page. To open About, use the About command below.

Edit the About page

Open Terminal and enter:

strange-country about

Press Return.

The About page opens in iA Writer. Edit it as you would any other document. iA Writer saves your changes automatically.

Your edits remain private and the live About page stays unchanged until you publish the changes.

To preview the About page, use strange-country preview and press Return. When you are finished previewing, press Control-C in Terminal. Use Control-C, not Command-C.

About does not need to be marked Ready. When you want to send the changes to the live website, enter:

strange-country publish "About"

Press Return. Check the proposed change, type yes, and press Return. When Terminal says YOUR CHANGES ARE NOW ON THE WEBSITE, the change is live.

Add an image

Each Post and Misc Musing has its own folder. Keep images used by a piece in that same folder.

In Finder, open:

Documents → Strange Country → content → Writing

Then open Posts or Misc Musings, followed by the folder with the title of the piece. Copy the image into that folder.

Give the image a short, descriptive filename made from lowercase letters and hyphens, for example:

railway-platform.jpg
old-city-map.png

Avoid spaces, capital letters, apostrophes, and other punctuation. Keep the file ending unchanged.

To place the image in the document or add a caption, see Images and captions.

Add or remove tags

Tags group related writing. Clicking a tag on the website shows other published writing with the same tag.

Use tags sparingly. Choose a small number of broad, useful topics someone might genuinely browse. Avoid long lists of highly specific tags; reuse an existing tag when it already describes the subject well.

For example, France, Wine is more useful than France, French Wine, Burgundy, Pinot Noir, Restaurants, Travel, Dinner, Paris.

Open Terminal and enter:

strange-country tags

Press Return.

Type one or more distinctive words from the title and press Return. If several pieces match, type the number beside the correct one and press Return.

If you know the exact title, you can instead enter:

strange-country tags "My Exact Title"

Press Return.

Strange Country shows the existing tags. Type any tags you want to add, separated by commas, and press Return. If you do not want to add any, press Return without typing anything.

If a similar existing tag is found, Terminal may ask whether to use the existing tag, create the new one, or skip it. Type the appropriate number and press Return.

Terminal then numbers the proposed tags. Type the numbers of any tags you want to remove, separated by commas, and press Return. Press Return without typing a number to keep them all.

Strange Country shows the final proposed list. Nothing changes until you type yes and press Return.

If the piece is already On website, tag changes remain private until you publish again.

Change the date or location

Strange Country normally uses the date on which a piece first appears on the website. You can show a different date when another date is more appropriate.

A location is optional. Examples include Paris or London, England. Not every piece needs one; use it only when it is genuinely relevant.

Open Terminal and enter:

strange-country details

Press Return.

Find the piece by typing one or more distinctive words from its title and pressing Return. If several pieces match, type the number beside the correct one and press Return.

If you know the exact title, you can instead enter:

strange-country details "My Exact Title"

Press Return.

Terminal shows the current date. To change it, type the date you want, such as 3 August 1914, and press Return. Type automatic and press Return to restore the first-publication date. Press Return without typing anything to leave the date unchanged.

Terminal then shows the current location. Type a new location and press Return, type none and press Return to remove it, or press Return without typing anything to leave it unchanged.

Strange Country shows the proposed date and location. Type yes and press Return to save them.

If the piece is already On website, the changes remain private until you publish again.

Change a title

Do not rename a Post or Misc Musing manually in iA Writer or Finder. Use Strange Country so the title and website address stay together.

Open Terminal and enter:

strange-country change-title

Press Return.

Type one or more distinctive words from the current title and press Return. If several pieces match, type the number beside the correct one and press Return.

If you know the exact current title, you can instead enter:

strange-country change-title "My Exact Current Title"

Press Return.

Strange Country shows the current title and asks for the new one. Type the new title exactly as you want it to appear and press Return.

Terminal shows the current and new titles. If the piece is already On website, its current title and address remain live until you publish the new title. After the new title is published, the old public address will continue to work.

iA Writer will close briefly while the title is changed, then the renamed document will reopen.

Check the proposed change, type yes, and press Return.

A Private piece stays Private. If the piece is already On website, publish when you are ready to send the new title to the live website.

Change the About portrait

A vertical photograph will usually fit the About page best.

In Finder, open:

Documents → Strange Country → content → Writing → About

The current image is called:

portrait.jpg

Prepare the new photograph as a JPEG and give it exactly the same name. Copy it into the About folder and choose Replace when Finder asks.

If the photograph is not already a JPEG, open it in Preview, choose File → Export, select JPEG, and save it as portrait.jpg in the About folder.

Preview the website afterward. The portrait will be sent to the live website the next time you publish the About changes.

Permanently delete writing

Use Delete only when you no longer want the piece on the live website and no longer want to keep or work on it privately either.

If you only want to remove a published piece from the live website while keeping the writing, use Unpublish.

Open Terminal and enter:

strange-country delete

Press Return.

Type one or more distinctive words from the title and press Return. If several pieces match, type the number beside the correct one and press Return.

If you know the exact title, you can instead enter:

strange-country delete "My Exact Title"

Press Return.

Strange Country shows the selected piece and exactly what will be deleted. It permanently removes the writing and images belonging to that piece. If the piece is On website, it also removes the public version.

A safety backup is created first. If iA Writer is open, Terminal warns before confirmation that iA Writer will close and reopen afterward.

Check the title carefully. To continue, type exactly:

DELETE

and press Return.

Anything else cancels the deletion. Strange Country confirms when the deletion is complete.

Do not delete Post or Misc Musing folders manually in iA Writer or Finder. Use the Delete command.

    Install Strange Country on a Mac

    Return to website help

    This installation is normally completed once. The repositories and public deployment should already be prepared before the permanent authoring Mac is connected.

    Before you begin

    You need a Mac, internet access, iA Writer, and access to the prepared private GitHub repository. Never place passwords, authentication codes, private keys, recovery codes, or confidential source documents inside the project folder.

    1. Put the project in its permanent location

    Move the unzipped folder into Documents and rename it exactly:

    Strange Country

    Its permanent location is:

    Home → Documents → Strange Country

    2. Check Homebrew

    Open Terminal and run:

    brew --version

    A version number means Homebrew is ready.

    3. Run the one-time setup

    cd ~/Documents/"Strange Country"
./scripts/setup_macos.sh

    The script checks or installs Hugo, Git, GitHub CLI, and Python, then installs the friendly strange-country command.

    4. Close and reopen Terminal

    Close every Terminal window. Open a fresh Terminal window and type:

    strange-country

    5. Connect this Mac

    Follow Connect this Mac to the existing website. The permanent Mac connects to repositories and deployment that already exist; it does not create them.

    6. Add one iA Writer location

    In iA Writer, add:

    Documents/Strange Country/content/Writing

    The location should show only:

    Posts
Misc Musings
About

    7. Check the complete system

    strange-country doctor

    The GitHub sign-in line may remain a warning on a separate preparation Mac using a repository-specific key. On the permanent Mac, the user signs into their own GitHub account.

    8. Open this guide at any time

    strange-country guide

    Press Control-C in Terminal to stop the local guide.

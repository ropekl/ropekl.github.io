Write and edit

New writing begins Private. It will not appear on the website until you mark it Ready to publish and then publish your changes.

Create a Post

Open Terminal and enter:

strange-country new

Terminal will ask for the title. Type it as you want it to appear on the website, then press Return.

Strange Country will create the Post and open the exact writing document in iA Writer. The command also shows its full Writing path. Never use Save As to create another copy of that document.

Create a Misc Musing

Choose Post for a full article. Choose Misc Musing for a shorter or more informal piece. Both are edited, previewed, and published in the same way.

strange-country new-musing

Type the title when Terminal asks for it. The exact musing document will open in iA Writer and remain private. The command shows its full Writing path so you can confirm the file before writing.

Begin writing

The writing document contains only your prose. Click in the empty document and begin writing. You do not need to type the title again at the top.

iA Writer saves changes on this computer automatically.

Each piece also contains website-data.toml. Strange Country uses this file to keep the piece connected to the website and to record its title, tags, dates, web address, and publication history. You will not normally need to open or edit it. Use the Strange Country commands when you want to change those details. iA Writer may show the file but does not normally open TOML files.

Keep the writing document, website-data.toml, and all images together in the piece’s folder.

For headings, links, quotations, footnotes, tables, images, and other Markdown, see Formatting your writing. For dialogue and scene conventions, see Formatting scripts and screenplays.

Open existing writing

Open iA Writer. In the Library on the left:

  1. Open Writing.
  2. Open Posts or Misc Musings.
  3. Open the folder with the title of the piece.
  4. Open the writing document inside it.

If a piece is already on the website, edits remain private until you publish again.

Edit the About page

strange-country about

The About page will open in iA Writer. Edit the text as you would any other document. Your changes remain private until you publish them.

Add an image

Each Post and Misc Musing has its own folder. Keep every image used by a piece in that same folder.

In Finder, open:

Documents → Strange Country → content → Writing

Then open Posts or Misc Musings, followed by the folder belonging to the piece. Copy the image into that folder, beside the writing document and website-data.toml.

Give the image a short, descriptive filename made from lowercase letters and hyphens:

railway-platform.jpg
old-city-map.png

Avoid spaces, capital letters, apostrophes, and other punctuation. Keep the file ending unchanged.

To place the image in the document or add a caption, see Images and captions.

Add or remove tags

strange-country tags

Type a few words from the title and choose the matching piece. Terminal shows the current tags, asks which tags to add, asks which tags to remove, then shows one final proposed list. Nothing is saved until you answer yes to the final question.

Tags appear discreetly at the end of the published piece, link to topic pages, and are included in the website’s quick search and full search.

Tag changes remain private until the next publication.

Change the date or location

Strange Country normally gives a new piece the date on which it first appears on the website.

To show a different date or add a location beneath the title:

strange-country details

Find the piece by typing part of its title, then follow the questions in Terminal.

Change a title

Do not rename the writing document or its folder yourself. Use:

strange-country change-title

Type one or more words from the current title. You do not need to type the whole title or match its capital letters exactly.

Strange Country first closes iA Writer normally and verifies that it has fully stopped. It then creates a safety backup, changes the title, folder, writing document, and future website address together, checks that exactly one verified Markdown document remains, and reopens the renamed document in a fresh iA Writer window. If iA Writer cannot close, nothing is renamed.

If the piece is already on the website, its public title and address remain unchanged until the next publication. Once the new title is published, every earlier public address will continue to work.

Change the About portrait

A vertical photograph will usually fit the About page best.

In Finder, open:

Documents → Strange Country → content → Writing → About

The current image is called:

portrait.jpg

Prepare the new photograph as a JPEG and give it exactly the same name. Copy it into the About folder and choose Replace when Finder asks.

If the photograph is not already a JPEG, open it in Preview, choose File → Export, select JPEG, and save it as portrait.jpg in the About folder.

Preview the website afterward. The portrait will be included the next time you publish.

Permanently delete writing

Use Delete only when you no longer want to keep the piece. To remove something from the website while keeping the writing, use Remove a piece from the website.

strange-country delete

Find the piece by typing part of its title. Strange Country shows exactly what will be removed and asks you to type DELETE. It then closes iA Writer safely, creates a complete safety backup, deletes only the selected folder, verifies that it stays deleted, and reopens iA Writer normally.

Deleting removes the writing document, website-data.toml, and every image in the piece’s folder. Do not delete the folder manually in iA Writer or Finder.

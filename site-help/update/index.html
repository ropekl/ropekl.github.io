Update Strange Country

Updates install tested improvements to Strange Country. They do not publish your writing or change what visitors currently see on the live website.

Run Update when you are told that a new update is ready.

Close iA Writer before you begin. Then open Terminal and enter:

strange-country update

Press Return.

Strange Country makes a safety backup, protects unfinished work, installs the latest changes, and checks that everything is working.

Keep Terminal open until the update is complete. If this computer is already current, Strange Country will say that no changes are needed.

When the update finishes successfully, reopen iA Writer and continue working normally.

If you use Strange Country on more than one computer, run Update before you start writing on a computer you have not used recently. This helps make sure it has the newest copy of your work.

If Strange Country finds that the same piece was changed separately on two computers, it will stop rather than overwrite either version. If that happens, ask for technical assistance.

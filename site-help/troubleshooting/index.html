Troubleshooting

When a command stops with a problem

Do not repeat the command immediately. Leave Terminal open and read the final message. Strange Country will tell you whether anything changed and what to do next.

To check the complete installation:

strange-country doctor

If everything is working, the final message will say:

STRANGE COUNTRY IS READY

If something needs attention, copy the final message and send it to the person helping you.

Terminal says “command not found”

In Finder, open Documents → Strange Country and double-click:

REPAIR STRANGE COUNTRY.command

When the repair is complete, close Terminal, open it again, and run strange-country doctor.

The preview is still running

Return to the Terminal window in which you started the preview. Hold down the Control key and press C once.

Publishing appears to be taking too long

Leave Terminal open. The Publish command will show periodic progress and report whether the website succeeded or stopped with a problem. If Terminal was closed accidentally, run:

strange-country status

You need something that was deleted

Stop making further changes and contact the person helping you. Strange Country created a safety backup before deletion. The writing, images, and website data should be restored together.

Remove something publicly without deleting it

Use:

strange-country unpublish

This removes the selected piece from the website but keeps its writing and images privately.

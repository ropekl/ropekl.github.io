Check or troubleshoot Strange Country

When a command stops with a problem

Do not immediately run the same command again. Read the final message in Terminal first.

To check Strange Country, enter:

strange-country doctor

Press Return.

Doctor checks the writing folder, the software Strange Country needs, the private backup connection, and the website build.

If everything is working, the final message will say:

STRANGE COUNTRY IS READY

If Doctor says:

STRANGE COUNTRY IS NOT READY YET

do not try to repair the problem yourself. Copy the final message and ask for technical assistance.

Doctor does not publish, overwrite, or delete any writing.

Only use:

strange-country doctor --details

Press Return only if you are asked to provide a detailed troubleshooting report.

Terminal says “command not found”

In Finder, open Documents → Strange Country and double-click:

REPAIR STRANGE COUNTRY.command

When the repair is complete, close Terminal and open it again. Enter:

strange-country doctor

Press Return.

The preview is still running

Return to the Terminal window in which you started the preview and press Control-C.

Use Control-C, not Command-C.

Publishing appears to be taking a long time

Leave Terminal open and follow the messages it shows.

If Terminal was closed accidentally, open Terminal and enter:

strange-country status

Press Return.

You need writing that was deleted

Stop making further changes and ask for technical assistance. Strange Country creates a safety backup before deletion, so restoration may be possible.

More commands

To see less frequently used Strange Country commands, enter:

strange-country help

Press Return.

For full instructions, use the Strange Country Guide.

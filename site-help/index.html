Strange Country Guide

This guide explains how to create, edit, format, preview, publish, and look after your Strange Country writing.

Choose a section below for step-by-step instructions.

Create, write, preview, and publish

Create and edit writing

Create a Post or Misc Musing, edit About, open existing writing, add images or tags, change details, change a title, or permanently delete writing.

Preview your work

See Private writing and unpublished changes in your browser before you publish them.

Get writing Ready and publish

Mark new writing Ready to publish, publish waiting changes, edit something already on the website, or remove a published piece while keeping it privately.

Formatting

Formatting your writing

Markdown instructions for headings, links, quotations, lists, images, footnotes, tables, and other formatting.

Formatting scripts and screenplays

Formatting for scene headings, action, character names, dialogue, parentheticals, and transitions.

Look after your work

Back up your work

Keep an additional private copy of all Strange Country writing and images.

Update Strange Country

Install tested improvements and bring this computer up to date with privately backed-up work.

Check the status

See what is Private, Ready to publish, On website, or waiting with unpublished edits.

Check or troubleshoot Strange Country

Run Doctor and follow the appropriate steps if something needs attention.

Setup

Set up Strange Country on another computer

Use the setup package to install and connect Strange Country on another computer.
